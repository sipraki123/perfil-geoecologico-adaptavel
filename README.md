# Perfil Geoecológico Adaptável

Desenvolvido por **João Sipraki**. Projeto pessoal independente.

Complemento experimental para QGIS que gera perfis geoecológicos configuráveis com faixas temáticas vetoriais ou raster. A versão **17.23.2** foi testada no **QGIS 3.44.13 para Windows**. O uso depende de entradas com SRC, geometria, cobertura e parâmetros adequados ao estudo; consulte as limitações e instruções incluídas no complemento.

## Distribuição e instalação

Baixe o pacote completo e o arquivo SHA-256 anexados à [Release experimental 17.23.2-r3-metadados](https://github.com/sipraki123/perfil-geoecologico-adaptavel/releases/tag/17.23.2-r3-metadados). Confira a integridade e extraia o pacote. No QGIS, use **Complementos > Gerenciar e Instalar Complementos > Instalar a partir do ZIP** e selecione somente o ZIP interno `Perfil_Geoecologico_Adaptavel_17.23.2.zip`.

O pacote inclui uma demonstração sintética. Seus valores são fictícios e não representam análise ambiental.

## Código-fonte

O código do complemento está em `perfil_geoecologico_adaptavel/`. `metadata.txt` registra a versão do complemento e a compatibilidade declarada.

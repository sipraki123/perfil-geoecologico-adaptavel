# Perfil Geoecológico Adaptável

Desenvolvido por **João Sipraki**. Projeto pessoal e independente.

Complemento experimental para QGIS que gera perfis geoecológicos configuráveis com faixas temáticas vetoriais ou raster. A versão **17.23.2** foi testada no **QGIS 3.44.13 para Windows**. O uso depende de entradas com SRC, geometria, cobertura e parâmetros adequados ao estudo; consulte as limitações e instruções incluídas no complemento.

## Distribuição e instalação

Baixe o pacote completo anexado à Release experimental `17.23.2-r2-docrev1` e confira seu SHA-256 com o arquivo de verificação também anexado. Extraia o pacote. No QGIS, use **Complementos > Gerenciar e Instalar Complementos > Instalar a partir do ZIP** e selecione somente o ZIP interno `Perfil_Geoecologico_Adaptavel_17.23.2.zip`.

O pacote completo inclui uma demonstração sintética, identificada como tal. Seus valores são fictícios e não representam análise ambiental.

## Código-fonte

O código do complemento está em `perfil_geoecologico_adaptavel/`. `metadata.txt` registra a versão do complemento e a compatibilidade declarada.
